
# BCity

BCity is a PHP project for to show case my abilities as a PHP programmer as requested by BCITY.

## Features

- CRUD operations
- Bootstrap 5
- DataTables
- AJAX Calls
- JQuery
- Database integration

## Installation

```bash
git clone <repository-url>
cd bcity
composer install
```

## Configuration

1. Copy `.env.example` to `.env`
2. Update environment variables
3. Run migrations: `php artisan migrate`

## Usage

```bash
php artisan serve
```

Visit `http://127.0.0.1:8000` to access the application.

## Requirements

- PHP 8.0+
- Composer
- MySQL
